# Jest Testing Practice

A small JavaScript project from The Odin Project focused on practicing test-driven development with Jest.

## Features

This project includes tests and implementations for:

- `capitalize`
- `reverseString`
- `calculator`
- `caesarCipher`
- `analyzeArray`

## Technologies Used

- JavaScript
- Jest
- ESLint
- Babel

## Getting Started

Install dependencies:

```bash
npm install
```

Run the test suite:

```bash
npm test
```

## Project Structure

```text
src/
  capitalize.js
  reverseString.js
  calculator.js
  caesarCipher.js
  analyzeArray.js

tests/
  capitalize.test.js
  reverseString.test.js
  calculator.test.js
  caesarCipher.test.js
  analyzeArray.test.js
```

## Purpose

The goal of this project is to practice writing clear unit tests and implementing small JavaScript functions based on those tests.
